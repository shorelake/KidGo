KataGo Web model download manifest

Model directory: ./web_service/models/
Download active models (from cpp):
  conda run -n go python -m web_service.download_models
Override directory: --directory PATH or KATAGO_MODEL_DIR
Model binaries and generated checksums are excluded from Git.
